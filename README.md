# Bilgi Yarışması · Knowledge Quiz (merkez-bilgi-yarismasi)

Bilgi Yarışması ailesinin **merkez uygulaması**: 12 bilgi oyununu tek mağaza uygulamasında toplar. Her oyun kendi deposundadır; ortak motor [bilgi-motoru](https://github.com/taktemurr-ops/bilgi-motoru), ortak çekirdek [studio-core](https://github.com/taktemurr-ops/studio-core). Harita verisi Natural Earth (kamu malı), ülke adları CLDR (Unicode lisansı) kaynaklıdır.
