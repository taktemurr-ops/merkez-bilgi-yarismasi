# Bilgi Yarışması · Knowledge Quiz (merkez-bilgi-yarismasi)

Bilgi Yarışması ailesinin **merkez uygulaması**: 8 bilgi oyununu tek mağaza uygulamasında toplar. Her oyun kendi deposundadır; ortak motor [bilgi-motoru](https://github.com/taktemurr-ops/bilgi-motoru), ortak çekirdek [studio-core](https://github.com/taktemurr-ops/studio-core). Harita verisi Natural Earth (kamu malı), ülke adları CLDR (Unicode lisansı) kaynaklıdır.

| Oyun | Depo |
|---|---|
| Genel Kültür | [oyun-genel-kultur](https://github.com/taktemurr-ops/oyun-genel-kultur) |
| Hangisi Daha? | [oyun-hangisi-daha](https://github.com/taktemurr-ops/oyun-hangisi-daha) |
| Bilgi Düellosu | [oyun-bilgi-duellosu](https://github.com/taktemurr-ops/oyun-bilgi-duellosu) |
| Dünya Haritası | [oyun-dunya-haritasi-yerlestirme](https://github.com/taktemurr-ops/oyun-dunya-haritasi-yerlestirme) |
| İller ve Plakalar | [oyun-turkiye-illeri-ve-plakalar](https://github.com/taktemurr-ops/oyun-turkiye-illeri-ve-plakalar) |
| Tarih ve Tarihler | [oyun-tarih-ve-tarihler](https://github.com/taktemurr-ops/oyun-tarih-ve-tarihler) |
| Elementler ve Bilim | [oyun-elementler-ve-bilim](https://github.com/taktemurr-ops/oyun-elementler-ve-bilim) |
| Hayvanlar ve Doğa | [oyun-hayvanlar-ve-doga](https://github.com/taktemurr-ops/oyun-hayvanlar-ve-doga) |
